# 11 — Gestión del proyecto

**Dueño:** Juan Manuel Espinosa (JME) (charter, sprint 01); cierre de sprint y post-mortem ambos · **Carpeta:** `project_management/`

## Loop

```
CADA DÍA (sprint de una semana, del 23 al 29 de noviembre):
  1. Revisar el sprint: estado de las tareas, bloqueos y desviaciones.
  2. Revisar el balance de commits: git shortlog -sn --no-merges.
  3. Al cierre: hitos del charter, riesgos materializados y post-mortem.
```

## Checklist

- [x] `charter.md` (1 página): alcance (hará / no hará), hitos con fechas, ≥ 5 riesgos con probabilidad, impacto y mitigación, roles.
- [ ] `sprint_01.md` actualizado durante la semana (objetivo, tareas con responsable y estado, bloqueos).
- [ ] `postmortem.md` (1–2 páginas) al final: hitos a tiempo o retrasados y por qué, cuellos de botella técnicos y
      organizacionales, qué cambiaría en producción, riesgos materializados.
